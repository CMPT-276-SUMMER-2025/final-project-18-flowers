## Taiwan Explorers  
### Group 18 Flowers
Names: Alex Lee, Ikkyu Li, Ryan Fu, Tian Zheng 

### Description 
A website designed to make exploring and planning a trip to Taiwan simple and accessible for users all over the world. It helps users discover iconic destinations, create personalized travel plans, and learn about Taiwan’s lively culture, history, and natural beauty.

### Tech Stack
- HTML/CSS/JavaScript/TypeScript
- React + Vite Framework

## Setup 
### Step 1
To get a copy, start by cloning the repository onto your local machine.
```PowerShell
git clone "https://github.com/CMPT-276-SUMMER-2025/final-project-18-flowers.git" 
```
### Step 2
Ensure that you cd into the right folder.
```
cd final-project-18-flowers
```
### Step 3 
Open VsCode and in your terminal, run npm install. 
```
npm install 
```
### Step 4
Finally, run the following command to see active changes while making changes to the code on your local machine. This starts the vite dev server. (Please ensure you have the .env file in your local repository) 
 ```
npm run dev 
```
